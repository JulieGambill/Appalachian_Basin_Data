## A Review of Appalachian Basin Region Earthquakes and Seismic Activity

### Project Description

A review of seismic events that occured in the Appalachian Basin Region between 1973 and 2015.  With an in-depth anaylsis of seismic events for the year 2013.

This project demonstrates data cleaning, wrangling, visualization, and analysis in Python.

----

### How to Use
1. Clone this repository.

2. Install the required Python packages:
```javascript  
     pip install -r requirements.txt
```
3. Open *Appalachian_Basin_Earthquakes.ipynb* in Jupyter Notebook.

----

### Usage Examples
The analysis shows an increase in seismic events for the year 2013 due to unnatural causes.
